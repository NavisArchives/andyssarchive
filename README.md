# UGC Portfolio starter
Open `index.html` locally, or deploy the folder free on Cloudflare Pages / GitHub Pages / Netlify.

## Replace content
- Portrait: replace `.portrait.placeholder` in `index.html` with `<img class="portrait" src="assets/photos/portrait.jpg" alt="Creator portrait">`.
- Portfolio: replace each `.media.placeholder` with a `<video ...>` or `<img ...>` from `assets/videos` / `assets/photos`.
- Logos: replace the text in `.logo-row` with image files from `assets/logos`.
- Change `hello@example.com` and social links.

Supabase is not needed for v1. Add it later only if you want an admin panel / CMS / enquiry database.
